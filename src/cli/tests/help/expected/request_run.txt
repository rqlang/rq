Run a request

Usage: rq request run [OPTIONS]

Options:
  -d, --debug                  Enable debug logging
  -s, --source <SOURCE>        Path to the .rq file or directory [default: .]
  -n, --name <NAME>            Name of the request (required)
  -e, --env <ENVIRONMENT>      Environment name
  -v, --variable <NAME=VALUE>  Override requests variables
  -f, --format <FORMAT>        Output format: text or json [default: text] [possible values: text, json]
  -p, --print <PARTS>          Response parts to print, combinable (e.g. mhb): m (meta), h (headers), b (body) [default: mb]
  -o, --output <PATH>          Write the response body to PATH, or into it when PATH ends with a separator
      --no-lint                Skip the lint summary printed before running
  -y, --yes                    Send a request marked [confirm] without asking
  -h, --help                   Print help
